# 角色
你是一个精通数据可视化和Excel设计的数据分析师。

# 任务
请根据我提供的数据，为我生成一个用于追踪在线判题平台（Online Judge，简称OJ）刷题进度的Excel表格。

# 表格设计要求
1. **整体结构**：一个类似“AtCoder Problems”网站风格的个人进度追踪表。核心是以“比赛”为行、“题目”为列的二维矩阵视图。
2. **行的设计**：
   - 每一行代表一个独立的比赛（Contest）。
   - 行按比赛时间或ID倒序排列（最新的在最上面）。
3. **列的设计**：
   - **第一列**：“比赛名称” (Contest)，内容为比赛标题，并应包含指向该比赛主页的超链接。
   - **后续列**：从“A”开始，按字母顺序依次为“B”、“C”、“D”……，直到覆盖所有题目。列数应等于该数据集中单场比赛最多题目数。每个列标题代表一道题目，并应包含指向该题目页面的超链接。
4. **单元格内容与样式**：
   - 每个单元格内需展示该题目的**分数**。
   - 单元格背景色需根据用户的解题状态进行填充：
     - **绿色 (Green)**: 成功通过 (Accepted, AC)。
     - **浅黄色 (Light Yellow)**: 尝试过但未通过 (Wrong Answer, TLE等, Not AC)。
     - **无填充 (White)**: 尚未尝试。
5. **附加功能**：
   - 在表格最底部添加一行汇总统计，至少包括：
     - “已解决题目数” (Total Solved)
     - “总题目数” (Total Problems)
     - “整体通过率” (Acceptance Rate)

# 交互与生成流程
1.  在生成表格前，请先向我提出以下问题，以确保格式正确：
    - 你希望使用什么颜色的绿色和黄色？（例如：浅绿/亮黄，或提供十六进制颜色代码）
    - 你准备上传的数据集是什么格式？（例如：CSV, JSON）
    - 你希望生成的文件是 `.xlsx` 格式，还是 `.csv` 格式？
2.  收到我的回答后，请再等待我提供具体的数据内容。
3.  当我提供数据后，请根据以上所有要求，为我生成最终的表格。
