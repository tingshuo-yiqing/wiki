## 树状数组求动态第 k 小：原理与步骤

### 一、前置知识：普通树状数组（Fenwick Tree / BIT）

BIT 的核心是**每个节点存储一段区间的和**。对于大小为 8 的 BIT，每个索引 `i` 负责的区间是 `[i - lowbit(i) + 1, i]`：

```
索引:   1    2    3    4    5    6    7    8
         \  /      \  /      \  /      \  /
覆盖:   [1]  [1,2]  [3]  [1,4]  [5]  [5,6]  [7]  [1,8]
```

其中 `lowbit(i) = i & -i`，即 i 二进制下最低位的 1 所代表的值。

- `bit[4]` 存的是 `[1, 4]` 的区间和（覆盖了 1,2,3,4 四个位置）
- `bit[6]` 存的是 `[5, 6]` 的区间和
- `bit[8]` 存的是 `[1, 8]` 的区间和

**BIT 的性质**：`bit[i]` 存储了以 i 结尾、长度为 `lowbit(i)` 的一段连续区间的信息。这是二进制提升能工作的根本原因。

---

### 二、核心问题转化

在 D_Median_Check 题中，BIT 的**每个位置代表一个值**（坐标压缩后），**存储的值是该值的出现频次**。于是：

> **"前缀和 prefix(i)"** = 原序列中小于等于第 i 个值的元素个数

查询**第 k 小**，等价于：找到最小的 i，使得 `prefix(i) >= k`。

---

### 三、方法对比：二分查找 vs. 二进制提升

#### 方法 A：普通二分（O(log²N)）—— 不推荐

```
每次猜一个 mid，调用 bit.sum(mid) 得到前缀和
比较前缀和与 k 的大小，缩小区间
二分需要 O(log N) 步，每步 sum 需要 O(log N)
总复杂度 O(log²N)
```

#### 方法 B：二进制提升 / Binary Lifting（O(log N)）—— 本题使用 ✅

**核心思想**：不是从外部二分，而是直接在 BIT 结构上"走"，利用 `bit[i]` 天然存储区间长度的特性。

**关键公式**：当我们站在位置 idx 时，`bit[idx + bitmask]` 存储的正好是从 idx+1 开始、长度为 `bitmask` 那一段的和！

> 为什么？因为当 `bitmask` 是 2 的幂时，对于任何 BIT 节点 `nxt = idx + bitmask`，如果 `lowbit(nxt) == bitmask`（即 nxt 的最低位恰好就是这个 bitmask），那么 `bit[nxt]` 覆盖的区间就是 `[nxt - bitmask + 1, nxt]` = `[idx + 1, nxt]`，恰好从 idx 后面开始！

**算法步骤**：

```
从 idx = 0 开始（当前已确认前缀和 >= k 的位置为 0）
bitmask 从 max_pow（≤ N 的最大 2 的幂）开始，每次折半

对于每个 bitmask：
  nxt = idx + bitmask
  
  如果 nxt <= N 且 bit[nxt] < k：
    说明"从 idx+1 到 nxt 这一段"的元素总数还不够 k
    → 把这一段跳过：k -= bit[nxt]，idx = nxt
  
  否则：
    说明第 k 小的元素就在这段里面，不能跳，缩小步长
  
  bitmask >>= 1（折半）

最后返回 idx + 1
```

      prefix(3) = bit[2] + bit[3] = 2 + 1 = 3  (3 < 5, 所以是 idx=4)
      第 5 小的值 = 压缩编号 4 = 原始值 4  ✅

#### 第四步：整体流程图

```
find_kth(k) 的执行轨迹（每一步决策）：

idx=0 ──[8]──→ ?       bit[8]=8 >= k → 不跳
idx=0 ──[4]──→ ?       bit[4]=6 >= k → 不跳
idx=0 ──[2]──→ 跳！    bit[2]=2 < k → k-=2, idx=2
idx=2 ──[1]──→ 跳！    bit[3]=1 < k → k-=1, idx=3
idx=3 → 返回 4

走的实际上是:
  先看是否在左半 [1~4] 内 → 是
  再看是否在 [1~2] 内   → 否，跳过前 2 个
  最后发现就是位置 4！
```

### 五、为什么要用二进制提升而不是二分？

| | 普通二分 + BIT.sum() | 二进制提升 find_kth() |
|---|---|---|
| 复杂度 | O(log²N) | O(log N) |
| 操作次数 | logN 次 sum，每次 logN | 直接走 logN 步，每步 O(1) |
| Python 表现 | 可能超时 | 稳妥通过 |

**本质区别**：普通二分是"猜 mid → 查前缀和 → 调整"，每猜一次都要从 BIT 根走一遍；二进制提升是"站在 BIT 上直接走"，每一步 O(1) 检查一个节点的值，因为这些节点恰好覆盖了正好 2 的幂大小的区间。

### 六、关键代码对应

```python
def find_kth(self, k):
    idx = 0                    # 当前已确认"不足 k 个"的位置
    bitmask = self.max_pow     # 从最大步长开始 (2的幂)

    while bitmask:
        nxt = idx + bitmask    # 尝试往前走 bitmask 步
        if nxt <= self.n and self.bit[nxt] < k:
            # bit[nxt] 覆盖的区间 [idx+1, nxt] 元素总数不够 k
            k -= self.bit[nxt] # 减去这一段的数量
            idx = nxt          # 跳过这一段
        # 否则：第 k 小就在 bitmask 覆盖的区间内，缩小步长
        bitmask >>= 1          # 步长折半

    return idx + 1             # 第 k 小一定在 idx+1
```

这就是树状数组通过**二进制提升**在 O(log N) 时间内求出第 k 小的完整原理。它巧妙利用了 BIT 节点天然覆盖 2 的幂大小区间的特性，相当于在隐式的线段树上做了一次"从根到叶"的 O(log N) 遍历。
