

### **A - 最良の練習相手 (Optimal Practice Partner)**
*   **核心考察：排序 + 优先队列（堆）**
*   **题目逻辑**：要在 $N$ 个候选中选出 $K$ 个人，使得“攻击力之和 $S \times$ 最小防御力 $M$”最大。
*   **解题关键**：固定其中一个变量。将所有人按防御力 $B_i$ 从大到小排序。遍历时，当前的 $B_i$ 就是 $M$。为了让 $S$ 最大，只需从当前已遍历过的人（防御力都 $\ge$ 当前人）中选出攻击力最大的 $K$ 个。利用**最小堆**动态维护这 $K$ 个最大攻击力。

### **B - ロッカーの整理 (Organizing the Locker)**
*   **核心考察：数论（因数与完全平方数）**
*   **题目逻辑**：对 $N$ 个储物柜进行 $N$ 次倍数切换操作，求最后开着的数量。
*   **解题关键**：理解“状态切换次数 = 编号的因子个数”。因子个数为奇数的数即为**完全平方数**。因此题目转化为：计算 $1$ 到 $N$ 之间有多少个完全平方数，答案为 $\lfloor \sqrt{N} \rfloor$。

### **C - 座席の案内 (Seating Arrangement)**
*   **核心考察：贪心算法 或 简单动态规划**
*   **题目逻辑**：一排座位，有些已坐人。要求在不违反“不能连续坐 3 人”的条件下，最多能新安排多少人。
*   **解题关键**：这是一个一维线性约束问题。可以从左到右贪心：只要当前位置为空，且填入后不会出现连续三个 $1$，就立即填入。

### **D - 配送センターの稼働計画 (Operation Plan for Distribution Center)**
*   **核心考察：中位数性质 + 滑动窗口**
*   **题目逻辑**：有 $N$ 个货物的期望配送日 $D_i$，中心只能连续开 $K$ 天。选择一个起始日 $s$，使得所有货物调整到区间 $[s, s+K-1]$ 内的配送总代价 $\sum |D_i - x_i|$ 最小。
*   **解题关键**：当窗口 $[s, s+K-1]$ 固定时，代价最小的 $x_i$ 取法是：若 $D_i$ 在窗外则取最近端点，在窗内则取 $D_i$ 自身。该问题的本质是寻找一个最优的 $s$，可以通过对 $D_i$ 排序后利用滑动窗口和前缀和在 $O(N)$ 时间内解决。

### **E - 散歩とバリケード (A Walk and Barricades)**
*   **核心考察：Bitset 优化的动态规划 (DP)**
*   **题目逻辑**：在数轴上从 $0$ 出发，有 $N$ 个移动计划（增加 $D_i$ 坐标），中间有 $M$ 个障碍物。询问在不撞障碍的前提下能达到的最大坐标。
*   **解题关键**：这是一个变种的子集和问题（Subset Sum）。由于坐标范围（如 $[-50000, 50000]$）相对于计划数较小，可以使用 `std::bitset` 来加速布尔型 DP 转移，将 $O(N \times \text{Range})$ 优化到 $O(N \times \text{Range} / w)$，从而通过 $10^5$ 规模的测试。
