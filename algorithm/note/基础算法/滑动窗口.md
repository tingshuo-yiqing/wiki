### 原理

滑动窗口主要处理**连续子区间问题**，随着窗口左右边界的移动必须要满足**单调性**。

1. 向右移动移动窗口时窗口某个性质单调。
2. 向左移动时会使该性质往相反方向变化。

即性质的变化为：**右扩 -> 可能不合法 -> 左扩 -> 恢复合法** 。

所以找到区间移动时可能的单调性很重要。

常见的维护的性质有：

* 元素频率（种类数）
* 权值（非负区间和）
* 最值/差值（配合单调队列）

### 应用

除了常见的可以维护的性质，还有常见的问题：

1. 定长
2. 不定长
   * 最长子数组
   * 最短子数组
   * 区间计数： `ans += r - l + 1` 
     * 无重复子数组： `cnt[x] <= 1` 
     * 最多 K 种元素： `distinct <= k` 
     * **恰好 K 种**： `atMost(k) - atMost(k - 1)` 

### 模板

定长一般有一个条件来判断窗口是否形成

```python
l = 0
# 初始化窗口
for r, x in enumerate(a):
    # 更新窗口状态
    if r + 1 >= k:
        # 再次更新窗口状态
        l += 1
```

不定长一般有个 while 循环来动态收缩窗口

```python
l = 0
# 初始化窗口
for r, x in enumerate(a):
    # 更新窗口状态 win
    while ...:  # 当窗口不满足条件时
        # 再次更新窗口状态 win
        l += 1
```

模板题：[双指针](https://www.nowcoder.com/practice/a2fd81391e1e4177aa6d506da895381b?tpId=386&tqId=11264996&channelPut=tracker1)   最长子数组 + 维护元素种类

要求记录每个最长不重复子数组的左右边界。使用哈希表维护当前窗口是否存在重复，然后有两种解决方法。

1. 先一次滑动窗口找出最值，然后再一次滑动窗口求出所有等于最值的区间边界。
2. 一次滑动窗口，在更新最值时清空答案数组。

具体代码为

```python
mx = l = 0
ans = []
cnt = defaultdict(int)
for r, x in enumerate(a):
    cnt[x] += 1

    while cnt[x] > 1:
        cnt[a[l]] -= 1
        l += 1

    d = r - l + 1
    if d > mx:
        ans = []  #! 更新时清空数组
        mx = d

    if  d == mx:
        ans.append((l + 1, r + 1))
```

模板题：[AWC Beta0026E](https://atcoder.jp/contests/awc0026/tasks/awc0026_e)  区间计数（恰好型） + 维护区间差值

对于一个 $K$ 我们要统计有多少对 $(l,r)$ 满足 $\max(A_l\cdots A_r)-\min(A_l\cdots A_r) =K$ 。这是恰好型的区间计数问题。

假如函数 $f(X)$ 是求 $$\max(A_l\cdots A_r)-\min(A_l\cdots A_r) \le K$$ 的个数，那么 $ans = f(K)-f(K-1)$ 。

1. 因为随着 $r$ 的右移，最值是单调的（最小值越小，最大值越大）所以可以使用滑动窗口。
2. 使用两个单调队列维护区间内的最值。

`atMost` 函数为

```python
def atMost(k):
    if k < 0:
        return 0
    midq = deque()
    mxdq = deque()

    ans = 0
    l = 0
    for r, x in enumerate(a):
        while midq and a[midq[-1]] >= x:
            midq.pop()
        midq.append(r)

        while mxdq and a[mxdq[-1]] <= x:
            mxdq.pop()
        mxdq.append(r)

        while a[mxdq[0]] - a[midq[0]] > k:
            l += 1
            if l > mxdq[0]:
                mxdq.popleft()
            if l > midq[0]:
                midq.popleft()
        ans += (r - l + 1)

    return ans
```
