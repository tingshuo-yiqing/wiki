常用于静态区间修改，树状数组的区修也用到了差分的原理。由于额外使用一个差分数组的增量差分写起来更简单直观，所以这里全部使用增量差分进行演示。

## 增量差分

使用一个全为 $0$ 的数组进行变化量的记录，要获得第 $j$ 个元素组的值只需要对差分数组进行前缀和再加上初始数组的值。
$$
复原后a_j=\sum_{i=1}^{i=j}d_i+a_j
$$
具体代码为

```python
def main():
    n, q = MII()
    a = LII()

    d = [0] * (n + 1)

    for _ in range(q):
        l, r, v = MII()
		
        # 这种写法是覆盖的范围是左闭右开的，即 [l, r]
        # 可以按情况修改比如 d[r] -= 1 就变成了 [l, r)
        d[l] += v
        if r + 1 <= n:
            d[r + 1] -= v
    
    cur = 0
    for i in range(1, n + 1):  # 处理的区间是 1-based 的
        cur += d[i]  # 对 d 进行前缀和
        print(cur + a[i - 1], end=' ')
```
