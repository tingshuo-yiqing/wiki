## 增量差分

使用一个全为 $0$ 的数组进行变化量的记录，要获得第 $j$ 个元素组的值只需要对差分数组进行前缀和再加上初始数组的值。
$$
复原后a_j=\sum_{i=1}^{i=j}d_i+a_j
$$
具体代码为

```python
def main():
    n, q = MII()
    a = LII()

    d = [0] * (n + 1)

    for _ in range(q):
        l, r, v = MII()

        d[l] += v
        if r + 1  <= n:
            d[r + 1] -= v
    
    cur = 0
    for i in range(1, n + 1):
        cur += d[i]  # 对 d 进行前缀和
        print(cur + a[i - 1], end=' ')
```

### 应用

最常见的应用就是进行区间修改。
