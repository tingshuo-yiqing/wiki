### [P2078 朋友 - 洛谷](https://www.luogu.com.cn/problem/P2078)

遍历每个节点，当 `fa[x] == x` 时，这个 `x` 就是该集合的根。

**代码链接**：[Link](https://vjudge.net/solution/68216851/Nuaxk5NnIJZs2N6cBxlr)

### [Roads not only in Berland - CodeForces](https://codeforces.com/contest/25/problem/D)
一个有 $n$ 个顶点，$n-1$ 条边的无向图，每次操作都删去一条边再加上一条边，使其变为连通图。
$n$ 个顶点 $n-1$ 条边的连通图是一棵树。**如果原图不连通，则一定存在若干个环**。我们可以利用并查集判断两个点是否已经在一个集合中；如果已经在一个集合中了，说明这条边是形成环的冗余边，需要记录并删掉。
最后需要加的边跟上一题类似，将所有集合的根连起来即可。

**代码链接**：[Link](https://codeforces.com/contest/25/submission/365357293)

### [Cycle Graph? - AtCoder](https://atcoder.jp/contests/abc404/tasks/abc404_c) 
判断单环的充分必要条件是：

1. 只有一个连通分量，所有节点都应该在这个连通分量里。
2. 所有节点的度数都恰好为 $2$。

第一个条件使用并查集判断，枚举 `[1, n]`，验证 `find(i) == find(1)`。如果有节点没有在同一个连通分量里，或者任意节点度数不为 $2$，就输出 `No`。

**代码链接**：[Link](https://atcoder.jp/contests/abc404/submissions/73866060)

### [小苯的蓄水池（hard）- 牛客](https://www.nowcoder.com/practice/06499d54e87d46569385652b2f954752?channelPut=tracker2) 

使用并查集将 `[l, r]` 区间的水池合并，并维护水池的水量总和与个数。
**注意**：在合并过程中不能直接使用 `for` 循环一个一个合并，数据量大时会超时（退化为 $O(N \cdot Q)$）。需要借助并查集自身的 `find` 进行跳跃优化。

```python
import sys

Max = lambda x, y: x if x > y else y
Min = lambda x, y: x if x < y else y

input_type = 0

if input_type:
    inp = lambda: sys.stdin.readline().strip()

    II = lambda: int(inp())
    MII = lambda: map(int, inp().split())
    LII = lambda: list(MII())

else:
    input_data = sys.stdin.read().split()
    it = iter(input_data)
    
    II = lambda: int(next(it))
    SI = lambda: next(it)
    
    if not input_data:
        sys.exit()

class DSU:
    def __init__(self, n, a):
        self.fa = list(range(n + 1))
        self.size = [1] * (n + 1)
        self.water = [0] * (n + 1)
        for i in range(n):
            self.water[i + 1] = a[i]
    
    def find(self, x):
        while self.fa[x] != x:
            self.fa[x] = self.fa[self.fa[x]]
            x = self.fa[x]
        return x
    
    def union(self, x, y):
        rx, ry = self.find(x), self.find(y)
        if rx != ry:
            self.fa[rx] = ry
            self.size[ry] += self.size[rx]
            self.water[ry] += self.water[rx]
    
    def cal(self, x):
        rx = self.find(x)
        res = self.water[rx] / self.size[rx]
        return f"{res:.10f}"

def main():
    n  = II()
    q = II()
    a = [II() for _ in range(n)]

    dsu = DSU(n, a)

    outs = []
    for _ in range(q):
        op = II()
        if op == 1:
            l, r = II(), II()
            cur = dsu.find(l)  
            while cur < r:
                dsu.union(cur, cur + 1)  # 要有方向的合并
                cur = dsu.find(cur)

        elif op == 2:
            x = II()
            ret = dsu.cal(x)
            outs.append(str(ret))

    print('\n'.join(outs))

if __name__ == "__main__":
    main()
