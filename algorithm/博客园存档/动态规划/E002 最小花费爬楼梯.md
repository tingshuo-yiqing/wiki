在这类问题中，我们的目标不是方案数（累加），而是**权重的最优值**（在范围内选最值）。跟据花费的不同，最小子问题也有差异。

---

### 类型一：花费为绝对值差

常见描述为：从 $i$ 跳到 $j$ ，花费为 $|h_i-h_j|$ 。

[Frog 1 - AtCoder](https://atcoder.jp/contests/dp/tasks/dp_b?lang=en) 

1. 定义状态：`dp[i]` 为到达第 $i$ 级台阶的最小花费。
2. 最小子问题：`dp[0] = 0` 、 `dp[1] = abs(a[1] - a[0])` 其余为无穷大。
3. 状态转移方程：$dp[i]=\min(dp[i],|h_i-h_{i-j}|+dp[i-j])$ 。$j$ 为 $i-K$ 范围内的合法的下标。

具体代码为

```python
def main():
    n, k = MII()

    a = LII()

    dp = [inf] * n

    dp[0] = 0
    dp[1] = abs(a[1] - a[0])

    for i in range(2, n):
        for j in range(1, k + 1): # 在可能到达i的j中找最小的那个
            if i - j >= 0:
                dp[i] = Min(dp[i], dp[i-j] + abs(a[i-j] - a[i]))
    
    print(dp[n-1])
```

### 类型二：花费为元素值

常见场景：只要落在第 $i$ 级就要支付 $a_i$ 的费用。

[Minimum Cost of Stepping Stones - AtCoder](https://atcoder.jp/contests/awc0033/tasks/awc0033_e?lang=en) 

1. 定义状态：`dp[i]` 为到达第 $i$ 级台阶时的最小花费。
2. 最小子问题： `dp[0] = a[0]` 。
3. 状态转移方程：$dp[i]=min_{i-K\le j <i}\{dp[j]\}+a[i]$ 。这里可以使用单调队列维护最值。

具体代码为

```python
def main():
    n, k = MII()

    a = LII()

    dp = [inf] * n
    dp[0] = a[0]

    midq = deque([0])  # 需要初始化索引0

    for i in range(1, n):
        if midq and midq[0] < i - k:
            midq.popleft()
        
        dp[i] = a[i] + dp[midq[0]]

        while midq and dp[midq[-1]] >= dp[i]:
            midq.pop()
        midq.append(i)
    
    print(dp[n-1])
```
