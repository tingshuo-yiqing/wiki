### 01背包

* **描述：**题面陈述通常为每件物品有价格（体积）和价值，每件物品只有选或不选且最多买一件。问在**不超过预算（容量）或花光预算**使买到的商品价值最大。
* **状态定义：** `dp[i][j]` 定义为前 $i$ 建物品放入容量为 $j$ 的背包的最大价值。
* **状态转移：**
  * 当前背包容量小于物品体积，即装不下时就不放人，直接继承前 $i$ 件物品的价值。 `dp[i][j] = dp[i - 1][j]` 。
  * 当前背包可以装下时，取一次 $\max$ 判断取了太价值会不会更大。 `dp[i][j] = max(dp[i - 1][j], dp[i - c] + w)` 。`c` 和 `w` 是第 $i$ 件物品的体积和价值。

#### 1. 不超过预算的最大价值

[AWC Beta0018D](https://vjudge.net/problem/AtCoder-awc0018_d#author=translator:1281309:zh)  

```python
def main():
    n, V = MII()

    W = LII()
    C = W[:]

    dp = [[0] * (V + 1) for _ in range(n + 1)]

    for i in range(1, n + 1):
        w = W[i - 1]
        c = C[i - 1]
        for j in range(V, -1, -1):
            if j >= c:
                dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - c] + w)
            else:
                dp[i][j] = dp[i - 1][j]
            
    print(dp[n][V])
```

#### 2. 花光预算的最大价值

与不超过预算的最大价值相比，仅仅初始化不同。默认 `f[i][j] = -inf` 即都不可达，然后 `dp[0][0] = 0` 可达且为 $0$ 。

[AWC Beta0052C](https://vjudge.net/problem/AtCoder-awc0052_c#author=translator:1281309:zh)

```python
def main():
    n, V = MII()

    W = [0] * n
    C = [0] * n

    for i in range(n):
        u, v = MII()
        W[i] = u
        C[i] = v
    
    dp = [[-inf] * (V + 1) for _ in range(n + 1)]
    dp[0][0] = 0

    for i in range(1, n + 1):
        w = W[i - 1]
        c = C[i - 1]
        for j in range(V, -1, -1):
            if j >= c:
                dp[i][j] = Max(dp[i - 1][j], dp[i - 1][j - c] + w)
            else:
                dp[i][j] = dp[i - 1][j]

    print(dp[n][V] if dp[n][V] != -inf else -1)
```
