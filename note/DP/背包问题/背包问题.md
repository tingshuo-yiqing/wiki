### 朴素01背包

* **描述**：在 standard 0/1 背包中，我们通常求“不超过预算”的最大价值；而这道题要求**价格恰好等于 $S$**。它们的区别仅在于**初始化**：
*   **不超过 $S$**：`dp` 数组全部初始化为 `0`。
*   **恰好等于 $S$**：`dp[0] = 0`，其余 `dp[1...S]` 初始化为 `-1`（表示不可达）。
* **例题**：
  *   [AWC Beta0052C](https://vjudge.net/problem/AtCoder-awc0052_c#author=translator:1281309:zh)  恰好等于 $S$ 时的最大价值
  *   [AWC Beta0018C](https://vjudge.net/problem/AtCoder-awc0018_d#author=translator:1281309:zh)  不超过 $S$ 时的最大值

### 可达性问题

*   **描述**：不求价值最大，只问能不能凑出。通常会使用一个大的二进制数来表示可达性。
*   **状态定义**：`dp[j]` 是布尔值，表示钱数 $j$ 是否可以达到。或 `dp` 初始化为 $1$ 再通过不断左移取补集来转移。
*   **状态转移**：`dp[j] = dp[j] | dp[j - x]` 或 `dp = dp | (dp << x)` 
*   **技巧**：在常用 `std::bitset` 优化，可以将时间复杂度降低 64 倍。
*   **例题**：
    *   [CSES - 1745](https://vjudge.net/problem/CSES-1745#author=translator:1281309:zh)  01背包可达性


### 求方案总数
*   **描述**：给定总额 $S$，求有多少种不同的组合方式可以恰好凑成 $S$。
*   **状态定义**：
*   **状态转移**：`dp[j] = dp[j] + dp[j - C[i]]`。
*   **注意**：如果是 0/1 背包，组合不考虑顺序；如果是完全背包，考虑顺序则变成爬楼梯/排列问题。

### 二维费用背包
*   **描述**：每件物品不仅有“价格”，还有“重量”或“体积”。你必须同时满足价格不超过 $S$ 且重量不超过 $W$。
*   **核心**：`dp` 数组增加一维，变成 `dp[j][k]`。
*   **复杂度**：$O(N \times S \times W)$。

### 分组背包
*   **描述**：物品被分成了若干组，**每组物品中最多只能选一个**。
*   **核心**：在处理每一组时，先循环容量 $j$，再循环组内的各个物品 $i$。这保证了同一组内不会选两个。
*   **应用**：比如在一个游戏中，你有多个槽位（头盔、铠甲、武器），每个槽位有多个装备可选，但每个位置只能穿一件。

### 有依赖的背包

*   **描述**：如果你想买物品 A（附件），必须先买物品 B（主件）。通常表现为树形结构。
*   **核心**：结合 **树形 DP**。对于每个节点，先递归处理子树，然后在父节点上做一次分组背包。

### 字典序最小/最大方案
*   **描述**：不仅要求最大价值，还要求输出具体选了哪些物品，且要求编号组成的序列字典序最小。
*   **核心**：在转移时，如果 `dp[j - C[i]] + V[i] == dp[j]`，需要根据编号大小决定是否更新。通常**倒着循环物品**（从 $N$ 到 $1$）更方便处理字典序最小。

### 目标价值下的最小费用
*   **描述**：如果物品的价格 $C_i$ 非常大（比如 $10^9$），但价值 $V_i$ 很小（比如 $100$），传统的 $O(N \times S)$ 会超时。
*   **核心**：**翻转状态**。定义 `dp[v]` 为“获得价值 $v$ 所需的**最小费用**。
*   **结果**：最后在 `dp` 数组中找到所有满足 `dp[v] <= S` 的最大 `v`。

### 完全背包与多重背包
*   **完全背包**：每件物品可以选无限次。循环顺序从“倒序”变为“正序”。
*   **多重背包**：第 $i$ 种物品有 $K_i$ 件。
    *   *常用优化*：**二进制拆分**。将 $K_i$ 件物品拆分成重量为 $1, 2, 4, 8...$ 的“包裹”，转化为 0/1 背包，复杂度从 $O(N \times S \times K)$ 降为 $O(N \times S \times \log K)$。
