## ST表

**ST表**（Sparse Table），也叫稀疏表

主要解决**静态RMQ问题**（区间最小、最大值）及其延伸。主要应用**倍增思想**，可以实现$O(nlogn)$预处理和$O(1)$的查询

ST表要求操作满足**等幂性**：
$$
f(x,x) = x
$$
这些操作要求：两个小区间的重叠不影响大区间的结果

常见的有：

- `min(x, y)`
- `max(x, y)`
- `gcd(x, y)`
- `and/or`

### 构建

1. 先预处理 `logs` 数组，实现 $O(1)$ 查询。

   ```python
   logs = [0] * (n + 1)
   for i in range(2, n + 1):
       logs[i] = logs[i >> 1] + 1
   ```

2.  动态规划预处理ST表

   ```python
   maxk = logs[n] + 1
   
   st = [[0] * n for _ in range(maxk)]
   
   st[0] = a[:]
   
   for k in range(1, maxk):
       # 枚举区间的起点i
       for i in range(n - (1 << k) + 1):
           st[k][i] = Max(st[k-1][i], st[k-1][i + (1 << (k-1))])
   
   def query_max(l, r):
       k = logs[r - l + 1]
       return Max(st[k][l], st[k][r - (1 << k) + 1]) 
   ```

### 查询

```python
l, r = MII()
l -= 1  # 这里需要转化为 0-based
r -= 1
outs.append(query_max(l, r))
```

## 第k级祖先

因为任意一个数都可以被拆成二进制的形式，即 $k=2^0 + 2^1 + \cdots + 2^x$ 。所以第 $k$ 级祖先不需要一步一步往上跳，我们可以预处理 `up[j][node]` 数组来进行大跳。时间复杂度优化至 $\log$ 级别。

### 构建

利用递推或动态规划来构建倍增表：

* **状态定义**：`up[j][node]` 表示节点 `node` 的第 $2^j$ 级祖先。
* **状态转移**： `up[j-1][node] = up[j-1][up[j-1][node]]` ，即 `node` 的第 $2^j$ 级祖先等于 `node` 的第 $2^{j-1}$ 级祖先的第 $2^{j-1}$ 级祖先。
* **跳跃方式**：枚举 $k$ 的二进制位，如果是 $1$ 就进行跳跃。

根据题目是给出明确的父子（上下级）关系和边关系，有两种初始化方式。

模板代码一为：

```python
fa = LII()
g = [[] for _ in range(n + 1)]
for u, v in enumerate(fa, start=2):
    g[v].append(u)  # 读取每个节点的父亲

# 对于 2^5 跳19次足够
LOG = 19

up = [[0] * (n + 1) for _ in range(LOG)]

for i in range(2, n + 1): 
    up[0][i] = II()
 
for j in range(1, LOG):
    for i in range(1, n + 1):
        up[j][i] = up[j-1][up[j-1][i]]
```

模板代码二为：

```python
g = [[] for _ in range(n + 1)]

# 读取无向边
for _ in range(n - 1):
    u, v = MII()
    g[u].append(v)
    g[v].append(u)

up = [[0] * (n + 1) for _ in range(LOG)]
dep = [0] * (n + 1)
dq = deque([root])

while dq:
    u = dq.popleft()
    for v in g[u]:
        if v != up[0][u]:
            dep[v] = dep[u] + 1
            up[0][v] = u
            dq.append(v)

for i in range(1, LOG):
    for j in range(1, n + 1):
        up[i][j] = up[i-1][up[i-1][j]]
```

在BFS的过程中还可以顺便求一下深度数组 `dep` 。

### 查询

```python
outs = []
for _ in range(q):
    u, k = II(), II()

    for j in range(LOG):
        if (k >> j) & 1:
            u = up[j][u]
            if u == 0:  # 到达0后就没必要再跳下去了
                break

    outs.append(u if u != 0 else -1)
```

## 倍增求LCA

得到了每个节点的深度后，在第 $k$ 级祖先的基础上求公共祖先。

求节点 `u, v` 的最近公共祖先的步骤为：

1. 默认让前一个节点是深度较深的。
2. 计算两节点的深度差 $k$ ，枚举 $k$ 的二进制位将 `u` 跳到与 `v` 同一高度。
3. 从最大步开始尝试， `u` 与 `v` 一起跳
   1. 如果跳 $2^j$ 后 `u, v` 的祖先相同，先按兵不动，因为可能不是最近的公共祖先。
   2. 如果跳 $2^j$ 后 `u, v` 的祖先还不相同，可以放心跳，因为距离最近的祖先还有一段距离。 

```python
outs = []
for _ in range(q):
    u, v = MII()

    if dep[u] < dep[v]:
        u, v = v, u

    k = dep[u] - dep[v]
    for j in range(LOG):
        if (k >> j) & 1:
            u = up[j][u]

    if u == v:
        outs.append(u)
        continue

    for j in range(LOG-1, -1, -1):
        if up[j][u] != up[j][v]:
            u = up[j][u]
            v = up[j][v]

    outs.append(up[0][u])
```
