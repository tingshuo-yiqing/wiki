def toposort():
    dq = [i for i in range(1, n + 1) if din[i] == 0]
    while dq:
        u = heappop(dq)
        topo.append(u)  # 这里储存拓扑序列
        for v in g[u]:
            # 这里进行图上的状态转移
            din[v] -= 1
            if din[v] == 0:
                heappush(dq, v)
    return len(topo) == n

## 应用

### 排序的唯一性与合法性

在进行拓扑排序的过程中，任意时刻中队列里只能有一个点，所形成的拓扑序列就是唯一的。其是**哈密顿路径的充要条件**。

字典序有两种，一种是全局的字典序最大最小，一种是相对的字典序最大最小。前者只需要使用对应的优先队列即可，后者需要建反图。

题目参考：

* [Course Schedule II](https://vjudge.net/problem/CSES-1757) 建反图
* [401. 从u到v还是从v到u？](https://www.acwing.com/problem/content/description/403/) 缩点后判断**拓扑排序的唯一性**，即判断是否存在哈密顿路径
