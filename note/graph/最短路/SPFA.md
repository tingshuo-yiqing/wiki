## 负环

模板：

```python
def SPFA(s):  # s 为起点，一般设置为超级源点
    dist = [inf] * (n + 1)
    dist[s] = 0
    cnt = [0] * (n + 1)
    inq = [True] * (n + 1)

    dq = deque([i for i in range(1, n + 1)])
    while dq:
        u = dq.popleft()
        inq[u] = False

        for v, w in g[u]:
            if dist[v] > dist[u] + w:
                dist[v] = dist[u] + w
                cnt[v] = cnt[u] + 1
                if cnt[v] >= n:
                    return True # 找到负环
                if not inq[v]:
                    dq.append(v)
                    inq[v] = True

    return False
```

注：

1. 判负环的标准做法是**初始时将所有节点都加入队列**，并将它们的 `dist` 设为 0。这样相当于建立了一个超级源点连接所有节点。
2. 不要忘记在出队时将 `inp[u]` 设置为 `False` 。

## 差分约束

**差分约束系统（System of Difference Constraints）** 是线性规划的一种特殊形式，它将一组代数不等式转化成**图论中的最短（或最长）路径问题**。

简单来说，如果你看到一组变量 $x_1, x_2, \dots, x_n$ 满足一系列类似 $x_i - x_j \leq w$ 的不等式，这就是差分约束。

### 一、 核心原理：为什么能转化成图？

观察最短路算法中的**三角形不等式**：
在图中，如果有一条从 $u$ 到 $v$ 权重为 $w$ 的边，那么最短路 $dist$ 一定满足：
$$
dist[v] \leq dist[u] + w
$$
变形得：
$$
$$dist[v] - dist[u] \leq w
$$
**发现了吗？这和差分约束的不等式形式完全一致！**

*   **变量 $x_i$** $\rightarrow$ 图中的**节点 $i$**。
*   **不等式 $x_i - x_j \leq w$** $\rightarrow$ 从**节点 $j$ 向节点 $i$ 连一条权重为 $w$ 的有向边**。

### 二、 常见的不等式转换

在实际做题中，条件往往不是标准形式，需要手动转换：

| 题目条件           | 转换后的标准形式                         | 连边方式 (从 $\to$ 到, 权)      |
| :----------------- | :--------------------------------------- | :------------------------------ |
| $x_i - x_j \leq w$ | $x_i \leq x_j + w$                       | $j \to i$, 权重 $w$             |
| $x_i - x_j \geq w$ | $x_j \leq x_i - w$                       | $i \to j$, 权重 $-w$            |
| $x_i - x_j = w$    | $x_i \leq x_j + w$ 且 $x_j \leq x_i - w$ | $j \to i (w)$ 且 $i \to j (-w)$ |
| $x_i < x_j$ (整数) | $x_i \leq x_j - 1$                       | $j \to i$, 权重 $-1$            |

### 三、 算法求解流程

1.  **建图**：根据不等式连边。
2.  **超级源点**：为了防止图不连通（导致漏掉某些变量的约束），通常建立一个虚拟节点 $0$，向所有节点 $1 \sim n$ 连一条权重为 $0$ 的边。
3.  **跑最短路**：通常使用 **SPFA**，因为差分约束经常会出现**负权边**（Dijkstra 无法处理）。
4.  **判断结果**：
    *   **存在负环**：说明不等式组**无解**（类似于出现了 $x_1 < x_2 < x_1$ 这种逻辑悖论）。
    *   **不存在负环**：$dist[i]$ 就是满足条件的一组可行解。

### 四、 差分约束的应用场景

#### 1. 区间选点/覆盖问题 (最经典)
**题目描述**：有 $n$ 个区间 $[a_i, b_i]$，每个区间至少要选 $k_i$ 个整数。求最少一共要选多少个点。
*   **转化**：设 $s[i]$ 为前缀和（$0 \sim i$ 选了多少个点）。
*   **约束条件**：
    1. $s[b_i] - s[a_i - 1] \geq k_i$ （区间限制）
    2. $s[i] - s[i-1] \geq 0$ （每个位置最少选 0 个点）
    3. $s[i] - s[i-1] \leq 1$ （每个位置最多选 1 个点）
*   **求解**：跑**最长路**（或将 $\geq$ 转为 $\leq$ 跑最短路）。

#### 2. 排队/布局问题
**题目描述**：一排人编号 $1 \sim n$，要求 $i$ 和 $j$ 之间的距离不能超过 $D$，或者不能少于 $d$。

*   **转化**：设 $pos[i]$ 为第 $i$ 个人的位置。
*   **约束**：
    *   $pos[j] - pos[i] \leq D$
    *   $pos[j] - pos[i] \geq d \rightarrow pos[i] - pos[j] \leq -d$
*   **求解**：跑最短路，若有负环则布局非法。

#### 3. 糖果分配/评分问题
**题目描述**：老师给孩子发糖果， $A$ 必须比 $B$ 多， $C$ 和 $D$ 必须一样多，求最少需要准备多少糖果。

*   这本质上也是差分约束，通常配合 $pos[i] \geq 1$ 这种基础约束来保证每个人都有糖。

### 五、 总结：最短路 vs 最长路

| 需求         | 转换目标           | 算法       | 判环       | 意义                                       |
| :----------- | :----------------- | :--------- | :--------- | :----------------------------------------- |
| 求**最大值** | $x_i \leq x_j + w$ | **最短路** | 负环则无解 | 受到上限约束，求能达到的最大上限           |
| 求**最小值** | $x_i \geq x_j + w$ | **最长路** | 正环则无解 | 受到下限约束，求能满足的所有下限中的最小值 |

**为什么你刚才问 SPFA 判负环？**
因为在差分约束中，**判负环是核心步骤**。如果 SPFA 跑出了负环，就代表你这一堆 $x_i - x_j \leq w$ 的逻辑在数学上是不可能成立的。
